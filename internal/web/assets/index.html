Restart safeguards

Only Notebook StatefulSet-managed Pods are supported. The server revalidates the live UID, owner chain, namespace protection and disruption budget, and rejects unmanaged, static, mirror or terminating Pods. No automatic force deletion is used; ambiguous interruption becomes needs-review.

Nodes

LIVE INVENTORY

Cordon safeguards

Cordon and uncordon prepare a server-validated plan before any change is submitted. The server revalidates the live Node, requires a reason, and requires Force for control-plane or NotReady nodes. Cordon never evicts existing running Pods.
